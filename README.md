# jetpack-compose-lab-smd

Practice 3: **Jetpack Compose phases** (Composition → Layout → Drawing).

An Android Studio project with 9 small demos that make Compose print what it does to Logcat,
so you can see which phase re-runs when a state changes.

| Read this | If you want |
|---|---|
| [DOCUMENTATION.md](DOCUMENTATION.md) | A simple explanation of the whole lab for a Python web developer |
| [PRACTICE_ANSWERS.md](PRACTICE_ANSWERS.md) | Answers to the 14 questions of the practice class, with measured Logcat results |

The demo code is in `app/src/main/java/com/example/jetpack_compose/phases/`.
Run the app, pick a demo with the chip row at the top, and filter Logcat with `tag:Phases`.
